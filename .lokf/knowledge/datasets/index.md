# Datasets

* [spdx LinkML schema](spdx-linkml-schema.md) - The LinkML schema of the SPDX 3.0.1 model (schema id `https://w3id.org/lmodel/spdx`, version 3.0.1): `spdx_linkml.yaml` imports one module per SPDX profile, 67 classes, 160 slots, 23 enums and 5 types in all, which scripts/spdx_to_linkml.py writes from the vendored model; its `lokf adapt` copy in `.lokf/spdx.yaml`, rooted on Element, is the bundle's domain schema.
* [SPDX model copy](spdx-model-copy.md) - `src/spdx_linkml/schema/upstream/spdx-model.ttl`, the SPDX Project's 3.0.1 model in OWL and SHACL as Turtle, retrieved from spdx.org under the Community Specification License 1.0; never edited here, the converter's only input, and compared byte for byte with the published file every week.
* [Generated artefacts](generated-artefacts.md) - Files generated from the spdx schema and never edited by hand: project/ (Excel, GraphQL, Java, JSON-LD, JSON Schema, OWL, a prefix map, protobuf, SHACL, ShEx, SQL and TypeScript), the dataclass and Pydantic models in src/spdx_linkml/datamodel/, the merged schema in docs/schema/, the gen-doc pages in docs/elements/ and the domain schema copy .lokf/spdx.yaml.
* [Test data and schema tests](test-data.md) - Example instances of the spdx schema in tests/data/: 54 valid files and 88 counter-examples, one for each constraint the schema states, each named after its class (Package-with-hash.yaml, Hash-missing-hashValue.yaml), which tests/test_data.py holds to the validator; beside them, tests/test_rdf.py writes the valid examples as RDF, tests/test_schema_is_generated.py fails on a hand-edited schema, and tests/test_schema_rules.py checks the adapt copy's names against LOKF's and three neighbour copies.
* [SPDX examples copy](spdx-examples.md) - tests/data/spdx-examples/, a copy of the SPDX Project's spdx-examples repository under GPL-3.0: 44 JSON files, 26 of them SPDX 3 documents in JSON-LD, which tests/test_data.py reads for class names, required fields and vocabulary values; the copy's links and spelling are upstream's, so the linters leave it alone.
