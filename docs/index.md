# spdx

A LinkML rendering of the System Package Data Exchange (SPDX) 3.0.1 model: one
module per SPDX profile, with every class, property and vocabulary keeping its
SPDX IRI.

- [Schema documentation](elements/index.md), generated from the schema
- [About](about.md): where the model comes from, what the rendering adds, and how it is kept current
